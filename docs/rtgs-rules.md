# กฎ RTGS ที่ระบบใช้

อ้างอิง: ราชบัณฑิตยสถาน, *หลักเกณฑ์การถอดอักษรไทยเป็นอักษรโรมันแบบถ่ายเสียง* (พ.ศ. 2542) ตารางทั้งหมดอยู่ใน [`src/transcribe/tables.ts`](../src/transcribe/tables.ts) และเรียกดูตอนรันได้จาก `RTGS_TABLES`

RTGS ไม่เขียนวรรณยุกต์ ไม่แยกสระสั้น-ยาว และไม่เขียนไม้ไต่คู้

## กฎพิเศษ

| กฎ | ตัวอย่าง |
|---|---|
| ควบแท้: กร กล กว ขร ขล ขว คร คล คว ตร ปร ปล พร พล ผล (และ บร บล ดร ฟร ฟล ในคำยืม) | ประเทศ prathet, ความ khwam |

| ห นำ หง หญ หน หม หย หร หล หว: ห ไม่ออกเสียง | หนู nu, ใหญ่ yai, หลวง luang |

## การแยกพยางค์

ที่ตำแหน่งตัวอักษรแต่ละตำแหน่ง parser จะสร้างพยางค์ทุกแบบที่เป็นไปได้ในรูป `[สระหน้า] พยัญชนะต้น [วรรณยุกต์] [สระ] [ตัวสะกด] [หางการันต์]` แล้วหาเส้นทางที่ต้นทุนรวมต่ำสุดจนจบคำ ([`syllable/costs.ts`](../src/syllable/costs.ts))

| ต้นทุน | กรณี |
|---|---|
| 0 | สระเขียนรูป ควบแท้ ห นำ การันต์ |
| 1 | ทุกพยางค์ (ถ้าต้นทุนเท่ากันให้เลือกแบบที่พยางค์น้อยกว่า) |
| 2–5 | ควบไม่แท้, ทร, ไ-ย, ว เป็นสระ, ควบกล้ำในคำยืม |
| 8 | ร ไม่ออกเสียงหลังตัวสะกด (ต้องมีสระเขียนรูป) |
| 10 | สระ o ที่ไม่เขียนรูป (คน khon) |
| 20 | สระ a ที่ไม่เขียนรูป (ถนน tha-non) บวกเพิ่มอีก 5 ถ้าอยู่กลางคำ และ 30 ถ้าอยู่ท้ายคำ |
| +20 | พยางค์สระไม่เขียนรูปที่ "แย่ง" ตัวสะกดของพยางค์เปิดก่อนหน้า (โรง-พ-ยา-บาล ไม่ใช่ โร-งพ-ยา-บาล) |
| 100 | อ่านอักษรตัวเดียวโดด ๆ เพราะเข้า template ใดไม่ได้ (มี warning `unparsed`) |

วรรณยุกต์ match ได้เฉพาะหลังพยัญชนะต้นหรือหลังสระบน/ล่าง ตัวที่มีวรรณยุกต์จึงเป็นพยัญชนะต้นเสมอ ซึ่งตัดทางเลือกที่ผิดออกไปได้มาก

## สิ่งที่กฎทำไม่ได้

สระที่ไม่เขียนรูปซึ่งเป็นพยางค์เชื่อมในคำบาลี-สันสกฤต (ราชการ rat-cha-kan, คุณภาพ khun-na-phap) สระท้ายคำที่ไม่ออกเสียง (ชาติ chat, เหตุ het) และคำอ่านเฉพาะ (กรุณา ka-ru-na) จะถูกเก็บไว้ใน [`dictionary/data/common-words.ts`](../src/dictionary/data/common-words.ts) ผู้ใช้เพิ่มคำของตัวเองได้ผ่านตัวเลือก `dictionary` หรือ `Romanizer.addWord()`
